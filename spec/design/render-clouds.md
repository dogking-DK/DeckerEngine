# 体积云设计

## 目标与边界

本设计包含已采用的云场契约及后续渲染计划；阶段顺序/状态见[Roadmap](../roadmap.md)。依赖
[大气M14](render-atmosphere.md)的太阳与透射接口、3D资源、深度采样、HDR合成和环境编辑链路。
首版提供单层球壳状积云/层积云、固定seed天气分布、风平移、云内/云下/云上观察、
太阳散射/自遮蔽、空气透视、时域稳定和地表云影；编辑器及无窗口截图使用相同内容输入。

不包含流体天气预报、降水/闪电、积雨云风暴、任意局部多体积、分层卷云、地形流送、
完整多次散射路径追踪或异步compute。无GPU时保留参数/持久化和CPU参考验证，不提供软件实时云渲染替代。
质量档和阈值是本引擎拟议目标，不能直接引用其他游戏的帧时作为本机结果。

## 技术方向与当前缺口

借鉴Nubis的可控程序化云场和分级渲染思路，以2D天气图约束3D基础形状/细节密度，
先做全分辨率无历史的有界射线积分，再加入半分辨率和时域重建。
依据：[SIGGRAPH 2017课程原始入口](https://advances.realtimerendering.com/s2017/index.html)、
[作者技术资料](https://www.schneidervfx.com/)。这些资料用于研究算法，不将其贴图、代码或演示性能直接纳入工程。

当前Graph可导入外部资源并管理单队列同步，但没有“跨帧Graph句柄”；ScenePipeline每帧独立分配输出，
不能假设已有TAA、运动矢量或历史池。M15的历史由Renderer按视图拥有，每帧重新导入真实资源。
现有M13只识别布料数值；环境截图/时间序列用有版本的独立渲染用例清单，复用Client、capture、
文件摘要和报告原则，不声称已有云参数扫描/恢复器。

## 模块与数据所有权

`engine/render/clouds`提供三个默认OFF的构建选项：`DK_BUILD_RENDER_CLOUD_FIELDS`构建
纯CPU `dk_render_cloud_fields` / `dk::render_cloud_fields`（PUBLIC Scene），
`DK_BUILD_RENDER_CLOUDS`同时构建GPU `dk_render_clouds` / `dk::render_clouds`（PUBLIC cloud_reference、graphics_device）。
`DK_BUILD_RENDER_CLOUD_REFERENCE`提供CPU `dk::render_cloud_reference`，PUBLIC fields/atmosphere_reference；
GPU clouds同时构建reference，并PRIVATE依赖Graph/Shaders。参考积分读取现有云场，不需要编辑器或命令层。
Scene/Services持有纯CPU CloudParameters；CloudFieldCache拥有不可变CPU天气/噪声代次，
CloudTextureCache拥有GPU纹理代次。模块不反向依赖Editor/Framework，不新增三方库。

### 参数、持久化与显式时间

EnvironmentDescription增加固定大小clouds；DeckerScene仍写v2，嵌套environment升级v2，
强制包含clouds。旧Scene v1或environment v1加载disabled云；environment v1迁移使用
top=min(4000,H/2)、bottom=min(1500,top/2)，兼容较薄大气。新写出统一environment v2。
命令query/set使用严格v2完整对象，旧v1 set拒绝，避免旧调用者无意覆盖云；迁移仅发生于磁盘读取。
clouds包括enabled、uint32 seed、generator_version=1、weather/base/detail_resolution，
bottom/top_height_m、coverage、density、extinction_per_m、weather/shape/detail_scale_m、
bottom/top_fade_fraction及水平wind_velocity_mps[2]（世界X/Z，每秒米）。
所有值即使disabled也校验：0≤bottom<top<大气顶，coverage[0,1]、density[0,10]、消光[0,1]，
尺度[1,1e7]米、两个fade各[.001,.5]、风各[-1000,1000]。
分辨率必须2的幂：weather[8,256]、base[8,128]、detail[4,64]，默认128/128/32。
生成器版本不支持时拒绝；相函数/光照参数由积分阶段定义，不添加未消费的占位字段。

sample_cloud_density输入完整环境、不可变场、世界位置及显式time_seconds（[-1e9,1e9]）。
密度为无量纲[0,density]，相对行星的球面高度约束垂直剖面；天气平面使用世界X/Z，
天气图与3D场都使用行星相对坐标，沿世界X/Z轴随水平风按p-wind*time平移，无帧累积和隐式时钟。
底/顶边界及壳外为0，coverage=0、density=0、disabled精确为0；消光系数供后续积分使用。
同一时刻重复/乱序调用产生相同结果，负时间有效。采样先检查有限输入及场key匹配。

### 确定性纹理与发布

生成器v1为周期整数格点value-noise的多频加权组合，固定uint32 hash和Q16平滑插值；
天气RG8保存coverage/type，base/detail为R8，线性过滤、repeat、单mip。
所有输出字节由整数计算确定，不依赖标准随机库、平台浮点舍入或线程调度。
字节FNV-1a摘要仅作内容诊断（非密码学）；身份key包含生成器版本、seed及三个分辨率。
密度/高度/coverage/风/时间变化不重建纹理。CPU bilinear/trilinear按GPU texel-center约定采样，
天气coverage阈值、type调节剖面顶端、base形状与detail侵蚀后夹取，具体公式由实现和锁定测试冻结。

两个cache均单线程所有者、不可复制，返回shared_ptr<const generation>保活旧代；
GPU cache额外持有退休代次，只在poll确认队列无在途提交、无其他录制批次且没有外部快照时回收，
防止提交仅保活Image而外部释放generation时漏计预算。借用image/view不延长父代次寿命。
同key返回当前代，不生成/分配纹理或提交GPU工作（仍校验队列身份）。不同key先校验预算、生成/分配，GPU上传提交并等待完成后才交换current。
失败（参数、预算、资源创建、记录/提交/等待）保留旧current及generation编号；异常分配由RAII保护，不承诺进程终止恢复。
默认至多2个活代（含current、外部保活旧代、待建候选）；第三代在生成前有界拒绝，释放旧代可重试。
CPU预算默认8MiB，统计活代纹理字节+候选；GPU预算默认16MiB，统计活代纹理字节+候选纹理+候选upload载荷。
预算是逻辑载荷而非分配器/显存硬上限；驱动对齐和scratch另由队列资源统计核验。
cache不暴露底层可变容器；纹理view按2D/3D类型创建，最终处于shader-read布局，队列提交保活资源。
队列必须属于创建cache绑定的设备/所有者；跨队列使用不支持。云场缓存无后台任务或历史；
ScenePipeline::render_environment在M15.3接入非零云的有界混合参考，范围见下文；未构建云GPU模块时明确拒绝。

验证覆盖固定seed独立重建字节/摘要、不同seed、范围/周期/插值、球壳/coverage/density边界、
显式时间暂停/跳跃/反向、预算和旧代保活、失效key、CPU-only编辑/事务/撤销/迁移/独立进程重载。
GPU要求真实设备、validation与sync validation，逐字节readback及shader过滤采样对照，
提交失败注入/代次额度/释放和关闭检查，不用skip替代通过。

后续视图/合成接口规划（当前云场及参考积分接口以各契约小节为准）：

| 输入/输出 | 后续约定 |
| --- | --- |
| CloudParameters | enabled、seed、球壳底/顶高度、coverage、density/extinction、形状/细节尺度、垂直剖面、风方向/速度、相函数及光照近似参数 |
| Weather map | 首版由固定版本生成器+seed生成2D coverage/type字段，CPU数据/摘要可追溯；暂不扩资产导入器支持外部气象数据 |
| Base/detail noise | 固定版本的程序化3D纹理，候选128³/32³；只在seed/生成器/分辨率变化时重建，不每帧重生成 |
| Per-view request | 与M14一致的ViewId、相机/投影/尺寸、显式time和frame、质量档、history策略 |

| Cloud shadow | 光空间2D透射图及覆盖范围/变换，只调制同一太阳直射项，不降低emissive或unlit颜色 |

范围校验包括底高<顶高<大气顶、非负消光、coverage∈[0,1]、非零采样尺度、有限风速与时间。

content seed和帧采样噪声seed分开，风由显式时间平移，不随实际帧率或线程调度累积。
所有预算（噪声字节、积分步数/距离、光线步数、视图数、在途代次）在提交前验证；无效输入不改环境或历史。

## 无历史参考积分契约

CPU `CloudReference.hpp`提供球壳区间、单射线参考；GPU `CloudReferenceRenderer.hpp`提供同步射线批参考。
每条输入射线完整执行指定步数，不做半分辨率、抖动、历史、早停或空区跳跃。
结果为曝光前RGB radiance、scalar transmittance、实际壳内积分长度、消光加权代表距离；
代表距离在零消光时为0，不是几何深度。最多两个有序壳区间，先裁到非负距离、max_distance和地面；
内球切点不删除有限长度，外球切点为空区间；地下起点拒绝，方向有限非零并稳定归一化。
CPU/GPU共同使用CPU求出的主射线区间，GPU太阳射线独立求交；高度和球根使用差平方/有理化形式。

默认主射线每区间256步、太阳每区间64步、大气太阳透射64步；分别允许1..4096、1..512、1..512。
max_distance有限[0,2e7]米，显式time_seconds沿用[-1e9,1e9]。
几何参考支持R[1,1e7]、大气厚度≤1e6、云壳厚度≥1米、行星中心各轴绝对值≤1e8；
射线起终点仍须在Scene位置范围内。GPU再要求R≥1000米且采样尺度≥100米（detail≥10米），
用每射线double预计算并周期归约的噪声原点、局部位移及稳定球面高度，避免把地球尺度世界坐标直接转float。
GPU超出支持域返回not_supported，禁止静默降精度。太阳路径不按相机max_distance截断。

ReferenceSettings持有显式模型版本1和实验光照参数，暂不扩Scene/命令协议；
这些是参考模型输入，须随测量记录，不暗称已可由GUI/持久化编辑。
相函数使用与大气相同、积分归一的HG，g∈[-.95,.95]（默认.6），cosine为视线与指向太阳的方向点积。
single_scattering_albedo∈[0,1]默认.9；sky_radiance为非负scene-linear RGB常量，默认0，
作为可关闭的各向同性天空漫射近似，不声称已经采样天空LUT。
太阳光乘同一环境的irradiance及大气到太阳的RGB透射；环境空气disabled时使用单位空气透射，
地球遮挡仍成立。直接大气透射只校验其AtmosphereParameters，不让默认云壳高度限制较薄大气；
云参考入口另行校验实际云壳。自遮蔽独立沿完整云壳积分云光学厚度tau，开关关闭时只去掉云自遮蔽，保留地球遮挡。

低阶多散射是显式三项能量受控再分配近似（默认strength=.35，可设0关闭）：
`(1-m)*HG(g)*exp(-tau) + m*(2/3*HG(g/2)*exp(-tau/2) + 1/3*HG(g/4)*exp(-tau/4))`，m∈[0,.5]。
所有相函数积分为1、权重和为1，降低高阶方向性/消光以近似光在云中的重新分布；
这不是完整路径追踪/光谱多散射，也不将差异当作步长误差。
每步先以中点取密度与源项，再用`1-exp(-sigma*ds)`（CPU expm1/GPU小量级数）精确积分常值步段，
前向累积`L += T*(1-exp(-sigma*ds))*source`、`T *= exp(-sigma*ds)`。
零coverage/density/extinction/disabled精确返回L=0/T=1；零太阳和零天空给L=0。
均匀密度诊断模式明确覆盖程序化密度，但仍遵守壳、enabled/零coverage及density倍率；
用于解析解和相同模型的步长检查，不能拿它代替真实场验证。

CPU每射线、GPU每批工作预算计算最坏`2*steps*(2*sun_steps+atmosphere_steps+1)`，
GPU最多4096射线、256M采样工作、4MiB输入/输出逻辑载荷；校验在分配/提交前完成。
GPU owner保存只读程序和队列身份，所有输入先验证/打包，host写输入→Graph计算→读回，等待完成并核验有限范围后
返回拥有型结果；错误不修改调用方数据、纹理current或旧结果。临时资源由Graph/队列保活并释放。
CPU没有缓存状态。GPU无帧历史或场景提交点；M15.2提供每射线参考，M15.3另由ScenePipeline完成图像合成。

开工冻结验收：均匀介质CPU解析误差≤1e-10、GPU≤2e-3；真实固定场256/64/64→512/128/128→1024/256/256，
最后两档T绝对差≤.005、RGB按`max(.01,参考最大通道)`归一误差≤2%，并记录较低档差异。
GPU与相同步数CPU固定射线集T绝对差≤.005、归一RGB误差≤2%。
覆盖云下/内/上、切线、地面阻挡、两段壳、固定seed/time、太阳正/逆向、自遮蔽及多散射开关、
薄/厚介质、纯吸收、零云、ray/work预算、外来队列、提交失败及旧资源可重用。
不把参考结果当作M15.3的空气/云合成，也不承诺本阶段实时帧时。

## 积分、光照与大气合成

1. 根据行星球壳、大气边界、相机和场景线性深度求出射线有效区间，正确处理从云内出发、
   切线、朝向地面及被几何截断；对向上无几何的射线采用物理边界/显式最大追踪距离。
2. 参考路径全分辨率、固定高采样、无历史，逐步积分Beer–Lambert透射及散射源项，
   步长改变时用一致的光学积分权重。初版有主光线和朝太阳的阴影光线最大步数，所有循环有界。
3. 云光照包括经大气衰减的同一太阳、云自遮蔽、参数明确的前向相函数、天空漫射近似。
   多次散射采用能量受控的低阶近似并单列开关/误差，不将艺术增亮称为物理精确。
4. 参考合成沿射线将空气与云的消光/源项共同积分；快速路径把无云空气区间与混合云区间
   统一表达为(L,T)，按相机到远处顺序组合：`(L1 + T1 * L2, T1 * T2)`。
   背景/表面辐亮度只在终端进入；不能将云颜色简单盖到已应用完整空气透视的天空/场景上再加一遍雾。
   从LUT取空气分段时，近零透射下避免相除放大误差，必要时走有界参考积分。
5. 日落时光线在大气中的衰减、云对太阳盘的遮挡、远云的空气透视必须同时成立。
   半分辨率合成使用几何深度保边上采样；alpha-mask孔洞沿已有深度结果处理，前景边缘不能漏云。

M15.3先完成无历史的合成正确性，之后才做优化；保留单独关闭云/空气/多散射/历史的诊断输出，
以零密度云严格退化到M14结果。reference只代表本次选定模型的高采样版本，不是完整光谱/多散射真值。

## M15.3 混合介质与图像合成实施契约

新增CPU混合空气/云参考及ScenePipeline显式`render_clouds`，`render_environment`按实际非零云自动装配。
纯CPU参考只含大气单散射；GPU可沿用快照的M14多散射LUT，独立CPU对照时关闭该闭合项，
GPU高采样对照保持相同模型。云源项复用M15.2；空气源项沿用M14，不包含云对空气太阳源/多散射场的反馈，
地表云影由下文的可选快照接入直射项。空气和云在观察路径上的RGB消光相加，源项相加后以常值步段解析权重积分。

用大气入/出点、最多两段云壳端点、D32重建的真实米制几何光程/地面组成至多五个有序区间。
云区间均匀中点，纯空气区间余弦分布节点；每区间使用请求的固定步数，不使用历史/早停/空区跳跃。
几何D32<1只在裁剪终点加入未施加空气透视的表面HDR，背景只在终端加入太阳盘（及关闭空气时的clear）。
太阳盘直接乘完整混合透射，不另乘整段空气透射；行星之后的终端源为零。tone只在最终HDR执行一次。
共享M14刚体有限forward-Z投影域，云密度仍用double周期归约原点和世界局部射线位移。

`CloudCompositionSettings`显式持有M15.2参考设置、surface_lighting/sun_disk/diagnostics及工作上限。
首版是无优化、逐输出像素的参考合成，最多4096像素，工作上限1Gi采样工作：
`pixels * 5 * steps * (2*sun_steps+atmosphere_steps+1)`；默认256/64/64。
CPU混合单射线也按五区间预检reference.max_work；原M15.2单介质参考仍按两区间计量。
不将该范围声称为完整分辨率编辑器实时渲染；超过范围明确拒绝，显式优化入口的范围见下节。
Scene/命令协议不增加字段；显式C++入口控制time/参考设置，共用环境入口使用time=0。

enabled=false、coverage/density/extinction为零时直接走原M14路径（空气也disabled则旧unlit），
最终HDR/RGBA8逐位退化一致。显式无云诊断入口仍保持各自语义。非零云允许空气disabled；
此时不积分空气，表面沿旧unlit，云照明使用无空气衰减的太阳。常量天空边界仍是M15.2显式近似。

可选诊断读回为两张RGBA32F：云源对观察者的散射RGB+云独立透射Tc；混合透射RGB+云消光加权代表距离（米）。
代表距离不是几何表面，零云消光时为0。诊断是独立拥有型帧资源，不覆盖最终线性HDR；
零云快速退化帧不生成云诊断，未请求/不匹配/未完成读回不写目标。
Graph声明depth/opaque→mixed compute→tone/readback；不执行M14整段AP后再覆盖云，也不相除重建空气分段。

缓存只保存不可变云场/纹理代次及静态程序，首次环境owner只在整帧提交成功后保留；
已有缓存可在准备阶段发布新纹理，但失败不改变Scene或旧帧，旧帧由提交保活实际资源。
新帧所有输入/预算/快照/队列验证，必要分配和返回容器在提交前完成。对象/录制/submit失败不返回半帧。
云与大气源码闭包纳入环境shader指纹。无新依赖，不引入CPU读回深度后再渲染的同步路径。

开工冻结验收：零云与原M14逐位一致；均匀混合吸收T解析误差≤2e-3；CPU/GPU同模型
固定像素及三档云/空气积分检查，HDR归一RMSE≤3%、p99≤8%（尺度=max(参考亮度p95,1e-3)），
遮挡/mask/地平线边缘独立误差≤8%；实际云独立透射对CPU绝对误差≤.005。
验证前景/云内/云后表面、mask洞、云遮太阳、远云空气透视、RGB吸收、曝光一次、固定seed/time重现、
显式云/空气/多散射诊断及required GPU同步/失败/关闭/在途寿命。输出最终图和透射/距离诊断PPM。

## M15.4 优化与时域实施契约

新增显式`render_clouds_optimized`，M15.3/reference和共用静态截图保持原入口及质量。
优化默认每轴二分（奇数尺寸向上取整），固定像素中心、不引入随机抖动；每区间至少96视线步、8太阳步，
长云区间按200m目标步长增加到最多256步，避免地平线长路径欠采样；工作预算按最坏256步预检。
超过100m的步段用4个等距中点平均密度，再积分该段消光；昂贵太阳光照仍每主步一次。
最坏采样预算包括这4次密度查询，GPU另用64位计数记录实际主密度查询数量。
低角度太阳（局部|cos天顶角|<.2）将自遮蔽提升至至少16步，其他方向保持请求的8步默认值。
空气太阳透射查已有T LUT，云和空气MS模型不变。输出最多1920×1080像素，单轴≤4096；
工作预算按最坏全像素回退加半尺寸积分计量：`(full+half)*256*(5+2*(2*max(sun_steps,16)+4))`，
分别覆盖至多5个空气区间、2个云区间及每次至多2段太阳射线；至多64Gi采样工作，主步数≤256、请求太阳步数≤64。
1080p是支持范围，不是实时性能达标声明。参考图仍使用M15.3三档收敛结果。

保守空区跳跃在天气/base双线性/三线性当前格子取角点最大值：
若weather上界不足coverage阈值，或base上界不足`1-coverage_upper`，该格子内真实密度必为零。
只跳过完全位于同一插值格子的主步，空气在合并步内继续积分；不按一次点采样判断后续空间为空。
混合最大通道T与独立云Tc均≤1e-4时可早停（可设0关闭），太阳盘方向禁用早停和插值，避免高亮终端放大误差。
GPU统计真实主步、空区略过、早停省略、云光照评估次数与回退/历史接受像素；不以预算估计冒充节省。

半尺寸输出L、RGB T、独立云L/Tc和代表距离，保存未曝光的介质量，不保存已合成表面色。
重建按几何距离/背景类别选邻域，非采样中心另检查3×3透射范围，避免两侧同值掩盖中间云边缘。
深度边缘、候选不足或邻域RGB T/Tc变化>.02时该像素直接重新积分；
终端几何/太阳始终用全尺寸深度和表面HDR，避免前景/mask漏云。曝光/tone只执行一次。

显式非零uint64 view_id隔离最多4个视图；camera_revision由调用者在换相机时改变。
每视图至多一份已完成源和一份在途候选，写新图像、读旧图像，绝不原地覆盖；同视图候选在途时有界拒绝。
`poll_cloud_history(queue)`只非阻塞查询完成并发布，成功提交但未完成不推进有效序号。
历史用云消光代表点、前帧相机和world X/Z风位移重投影；深度/背景冲突、越界、云透射差异≥.01或低云置信拒绝。
当前3×3邻域夹取L/T和云L/Tc，再按至多.9（默认.85）权重混合；无有效历史则直接使用当前积分。
无几何运动矢量，Scene revision变化整体重置；连续相机/显式风时间可重投影。

新视图、尺寸/投影、camera_revision、Scene身份/revision、环境/seed/质量/参考模型变化、时间倒退或delta>1s、
相机平移>500m或旋转>15度、显式释放重建、前次录制/提交失败均重置；曝光不重置。
Shader/device由不可变Pipeline实例拥有，重建实例自然清空历史，不承诺源码热重载。
失败保留旧Frame和已完成序号，标记下次不可复用；不发布失败候选。视图释放需先完成该视图在途工作。
历史只持有三张半尺寸RGBA32F，不保留整帧Graph/表面输出；GPU/Frame仍保活真实资源。
所有视图源与候选逻辑载荷合计上限256MiB；无隐式淘汰、不复用跨帧Graph句柄。

开工冻结：静态与连续相机/风的HDR相对收敛参考nRMSE≤5%、p99≤12%，边缘/反遮挡区域最大≤12%，
尺度=max(参考亮度p95,.001)；真实云Tc绝对误差≤.02，均匀纯吸收T≤.002；零云逐位退化M14。
固定镜头预热32帧后120帧归一化帧差RMS≤1%；暂停/回退/切换/失败恢复可重复。
分别比较关闭跳跃/早停/历史及全尺寸参考，证明空区与厚云有真实工作量下降，半尺寸路径有真实重建复用。
required GPU同步验证和预算/外来队列/提交故障/多视图/关闭/在途寿命必须通过；性能目标和三轮报告仍在M15.7验收。

## 云影与交互闭环

M15.5提供显式CloudShadowRenderer/CloudShadowMap与日光/空气/云合成的可选快照参数。
单层云底以下接收体使用太阳正交R32F云透射图；仅乘太阳直射，不修改天空漫射、自发光、
太阳盘或观察路径云/空气积分。未传快照保持已有行为；共用编辑器/capture自动配置留给M15.6。

固定世界center_m与extent_m定义太阳正交平面，U/V仅由太阳方向确定，不依赖相机。
每条平行太阳射线从云底球面朝太阳一侧的交点积分至云顶，云底以下沿同一直线的接收体共享完整云柱。
行星遮挡仍由M14日光处理；投影不穿过云底球的像素为单位透射。世界噪声坐标/风时间先以double约化，
GPU仅接收球面高度/路径和重复纹理相位，避免世界大坐标消减。太阳改变重建投影，风/time改变云柱。
接收体全部顶点包围盒须在云底球内及图的半像素安全边界内，超界拒绝整帧，不静默无阴影或夹边。
首版不支持云内/云上接收体、自动跟随/级联、云对空气MS的反馈或复杂体积光束。

默认256²、256步/云柱、8192m覆盖，resolution为16–512的2次幂，steps≤1024，extent为[16,65536]m；
time在±1e9s，center分量≤1e9m。采样工作≤128Mi次，单代CPU/GPU逻辑载荷≤64MiB；
每个renderer至多3个活代、总载荷≤64MiB（包含CPU候选射线、上传、图与可选读回的保守计费）。
创建与prepare不隐式等待GPU；同队列Graph导入消费storage→fragment sampled，未完成时拒绝CPU读回。
命中完整环境/质量/time/区域键复用相同代，相机移动不参与键；非零云与零云均输出真实图像，零云严格1。
提交前准备所有候选和容器空间，成功submit后发布当前快照/递增代号；任何校验/分配/录制/提交失败保留旧图。
旧图、Frame和在途提交均保活资源；最后使用的提交完成且无外部快照/Frame时才从活代预算移除。
跨队列、纹理/环境不匹配、关闭或额度超出明确拒绝；消费云合成时time与均匀诊断模型须一致。

开工冻结验收：均匀径向/斜向云柱对Beer–Lambert误差≤.002；真实云柱GPU对同模型收敛CPU
透射误差≤.02，相邻加倍采样参考收敛差≤.005；256→512→1024未收敛时继续至2048/4096，不放宽误差门槛；双线性地表采样对独立直射参考误差≤.03。
检查太阳投影、风向和时间恢复、固定世界点随相机移动稳定（线性RGB≤1e-5）；零云逐位等于原M14。
验证只改变直射（天空漫射/自发光差量≤1e-5）、太阳能量比例、alpha-mask、联合云/空气不重复衰减。
必须通过required GPU同步validation、参数/代次/字节预算、外来队列、创建/submit失败、重试、关闭和在途寿命。
本节不验收1080p帧时/192MiB性能目标，不将光空间分辨率或逻辑预算冒充完整场景显存测量。

M15.6通过统一environment命令修改云；GUI预设、undo/redo、保存/重载、runner截图与Python/Luau保持一致。
界面区分物理参数和质量参数，显示实际生效版本/历史重置原因；预设显式写入seed与生成器版本。
独立渲染清单固定相机、太阳高度、coverage、seed、时间、质量和预算，输出图像、线性数值摘要、
环境/二进制/shader指纹及性能报告，失败项保留错误/缺失，不伪装为零耗时或有效图像。

## 验证、质量和性能候选目标

阶段见M15.1–M15.7。至少覆盖晴空、稀疏/厚云、逆光、日落、地面/云内/云上、前景剪影、
固定seed复现、静止及平移/旋转相机、风动画、暂停/时间跳跃、resize、取消/失败和关闭。
CPU参考验证均匀介质解析解、区间组合、密度范围、确定性与量纲；GPU验证storage写入→采样、
历史导入/读写隔离、对象寿命和同步validation，无可用设备的跳过不能替代验收。

初始候选门槛：零云状态与M14参考一致；均匀介质透射绝对误差≤2e-3；
静态Balanced相对收敛参考线性RGB归一化RMSE≤5%、p99≤12%，归一化尺度同大气设计。
固定镜头预热32帧后的120帧序列，归一化帧差RMS候选≤1%；相机切换后的首帧必须拒绝旧历史。
动态路径以相同时间的无历史参考逐帧比较，并单列边缘残影/反遮挡区域，不能用静态收敛替代动态质量。
具体参考收敛、动态阈值及曝光固定值在M15.2/4开始优化前冻结，变更须留证，不事后调阈值掩盖失败。

同一实测设备/构建、1080p Balanced的候选目标：云积分+重建+合成+云影增量GPU p95≤4ms，
大气与云合计p95≤5.5ms（测组合区间，不能直接相加各Pass p95），环境资源稳态≤128MiB、
含旧代在途的峰值≤192MiB。无实测前不承诺60fps或指定设备达标；基础场景成本另计。
沿M11记录预热/冷启动、CPU建图/提交、GPU timestamps、端到端、显存和采集开销；
至少三轮固定序列，报告原始样本、p50/p95及失败。正确性开validation，性能另记录关闭validation的条件，
不将readback/捕获等待当成云GPU耗时，不累计重叠的父子GPU区间。
