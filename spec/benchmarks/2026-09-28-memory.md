# M1.7.7 Memory 初始性能基线

256 B / 64 B 对齐、32 线程时，arena 和 local pool 吞吐较高。arena 在 Memory 采集下的耗时达到 OFF 的 75.710 倍。线程调度有波动，这组数据只用于同机合成负载对照。

Ryzen 9 7940HX，Windows x64。每配置独立运行三次，预热 32 轮、测量 512 轮，batch 16。
